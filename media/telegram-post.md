# Пост для Telegram

Прикрепить: `media/reel.mp4` (вертикальное видео, 44 с, без звука).
Альтернатива — альбом из 3–4 роликов: `hero.mp4`, `portrait.mp4`, `quiz.mp4`, `cake.mp4`.

---

🎂 Сделал интерактивную открытку на день рождения, которая сама себя рисует

Портрет прорисовывается по линиям и заливается акварелью, дальше — мини-квест по «Ведьминой службе доставки», желание, которое уносят одуванчики, и торт, который сам садится в открытку под конфетти.

Что внутри:
• SVG-прорисовка по штрихам + акварельная маска на feTurbulence
• FLIP-анимация: торт улетает в слот открытки
• звуки интерфейса синтезируются через Web Audio API
• drag & drop на Pointer Events (мышь и тач)
• без фреймворков — чистые HTML / CSS / JS

👉 Демо: https://gifts-happy-birthday.vercel.app/
💻 Код: https://github.com/apostol0525/for-you

Лучше открывать с телефона 📱
