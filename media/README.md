# Media — how to record the demo GIFs

For an animation-heavy project, smooth GIFs sell it. Record locally (crisp + smooth) rather than auto-capturing.

## Tool (Windows, free)

**ScreenToGif** — https://www.screentogif.com
- Record a region → trim → **Reduce frame count** / set ~30fps → **Save as GIF** (or MP4 for even smaller size).
- Target width ~480–640px, keep clips **2–5s**, loop on.

(macOS: CleanShot X / Kap. Any OS: OBS → convert to GIF.)

## Shot list (record these, name them like below)

| File | Moment | How to trigger |
|------|--------|----------------|
| `hero.gif` | Line drawing → tap → watercolor rises | Open the page, let lines draw, tap once |
| `portrait.gif` | Kiki portrait: contours → watercolor bloom | Hero → tap → "open" → the birthday section |
| `transition.gif` | 3D slide between sections | Any "next"/answer that changes screen |
| `cake.gif` | Cake draws big → shrinks & docks into the card | Make a wish / skip → final section |
| `particles.gif` | Gold star sparks + confetti | Tap a button; reach the final confetti |
| `dragdrop.gif` | Drag a photo onto a shelf | "Разложи моменты по полочкам" section |

## Use in the main README

Drop the files here and they'll show via the paths already referenced, e.g.:

```md
![Portrait reveal](media/portrait.gif)
```

Tip: put the single best clip (portrait or cake) at the very top of the README and the repo/Behance cover.
